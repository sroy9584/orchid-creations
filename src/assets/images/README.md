# Founder Photograph Location

Upload your official photograph here:

- Preferred file: `public/assets/images/sourav-roy.jpg` or `src/assets/images/sourav-roy.jpg`
- Alternative: `.png` or `.webp` format.
- Aspect ratio: 4:5 or 3:4 portrait (recommended 800 x 1000px).

To update the displayed photo, simply upload your photo to this directory and update `founderPhotoPath` in `src/data/siteConfig.ts` if using a different filename.
