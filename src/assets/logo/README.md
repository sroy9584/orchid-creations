# Official Orchid Creation Logo Location

Upload your official logo files here:

1. **Vector SVG Logo (Preferred)**:
   - File path: `public/assets/logo/orchid-logo.svg`
   - Transparent background.

2. **High-Resolution PNG Logo (Alternative)**:
   - File path: `public/assets/logo/orchid-logo.png`
   - Transparent background (recommended 600px+ width or 512x512).

3. **Open Graph Social Share Banner**:
   - File path: `public/assets/logo/orchid-og-banner.png`
   - Dimensions: 1200 x 630 px.

The website navigation bar and footer automatically use this logo via `siteConfig.ts` (`logoPath`).
